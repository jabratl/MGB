4.1 Existing style (do not change)
 - Material3 DayNight NoActionBar, theme Theme.MGB. Views in code. System sans-serif only (no custom font). Typeface.create("sans-serif-medium", ...) for titles.
 - Tokens (res/values/colors.xml light | values-night/colors.xml dark):
     mg_bg #FFFFFF | #0A0C10     mg_surface #F5F5F7 | #14171C     mg_surface_variant #ECEDF0 | #1F232A
     mg_primary (rose) #D93A5C | #F2708A     mg_on_primary #FFFFFF | #3A0A15
     mg_text #14171C | #ECEFF4     mg_text_dim #5F6673 | #98A0AE     mg_outline #DCDFE5 | #2A2F38
     mg_error #D93025 | #FF7B72     mg_success #1E9E5A | #4CD08A     thazir_icon_bg #1B1630
   Always getColor(R.color.x); never hard-code hex in Kotlin (except TabPrefs.tint HSV).
 - Text sizes: screen title 22sp bold medium (header 56dp, back button 44x48dp padding 10dp); card title 16sp medium; row label 15sp; row hint 12sp (mg_text_dim); group label 11sp UPPERCASE letterSpacing 0.08 medium in mg_primary; search box 15sp; bar engine letter 13sp bold.
 - Spacing: screen side padding 16dp, bottom 32dp; card = round(mg_surface, 24dp) + 1dp stroke mg_outline alpha 0x99, cards 12dp apart; row min height 52dp, padding 18/6/16/6dp; row icon 22dp + 16dp gap; category badge = 42dp squircle, radius 13dp, fill TabPrefs.tint alpha 0x2B, icon 22dp tinted; dividers 1dp mg_outline inset 16dp; bottom pill bar 52dp / radius 26dp / margins 10-6-10-8dp; dialogs radius 16-24dp; undo bar = surface_variant radius 16dp elevation 8dp.
 - Dark / light: automatic through values-night; status + nav bars = mg_bg; light bars flag mg_light_bars. Test every screen in BOTH modes.
 - Breakpoints: no width classes. Only phone check: smallestScreenWidthDp < 600 (Orient.kt) and landscape check (Configuration.ORIENTATION_LANDSCAPE). New screens: scrollable column, no fixed heights, must work in landscape.
 - Icons: 24dp vector XML, tinted by setColorFilter. Selected row flash / chevron rotation exist in SettingsScreen (reuse by calling its helpers, do not re-invent in other screens).
4.2 NEW tokens (added in A1)
     mg_toggle_on  light #5B4BD6 | dark #9A8CFF   (Thazir violet, same family as the launcher icon background; NOT red, NOT the rose accent)
     mg_toggle_thumb #FFFFFF (both modes)
   Rose (mg_primary) stays the brand accent for labels / progress / buttons. Violet is only for switches and "selected" rings in Appearance.
4.3 UNIQUE Thazir look (this is what makes it different from the reference video)
 - ThazirSwitch (class ThazirSwitch : MaterialSwitch, drop-in, same API): track 48x28dp pill; ON = solid mg_toggle_on, OFF = transparent with 1.5dp mg_text_dim (alpha 0x80) outline; thumb = ROUNDED SQUARE 20dp radius 7dp (not a circle): ON = white with a small check in mg_toggle_on, OFF = mg_text_dim. Reference uses a red round-thumb switch: ours differs in colour AND shape.
 - No radio circles anywhere. Single choice = tiles / chips: selected = 2dp mg_toggle_on ring + small check dot top-right; unselected = 1dp mg_outline.
 - Theme picker = 3 mini-phone preview tiles (System = half light / half dark, Light, Dark), each ~100x120dp, radius 16dp, label under it. Bar position picker = 2 mini-phone tiles with the pill drawn at top or at bottom. Home-button action = wrap of chips (icon + label, radius 20dp).
 - Appearance root rows use the same category-style squircle badge (tint key "appearance" = hue 330, add to TabPrefs.HUE only if A2 touches TabPrefs; otherwise pass the colour directly).
 - Motion: 150-200ms alpha/scale only; respect TabPrefs.reduce(ctx) (skip animations when true).
4.4 Mobile first: all targets >= 44dp; text never below 11sp; check 360dp wide portrait and landscape.
