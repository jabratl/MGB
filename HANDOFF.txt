======== ARCHITECTURE (what exists) ========
- ChromeBridge (object): native side of the shim. on(api){Call}, onSync(api){Call->result}, emit(event, JSONArray){ctx->Boolean}, request(ctx,msg,sender,cb) (runtime.onMessage to one frame), contexts(), bindTab/unbind, storage areas local/sync/session (ChromeBridge.local/sync/session .get(...)). Ctx has kind (CONTENT/EXT), web, origin, isMainFrame, tabId. Call has ctx, api, args, ok(x), fail(msg). Page frames (CONTENT) may only use runtime.sendMessage + storage.local/sync.
- assets/shim/chrome-shim.js: forwards every chrome.<ns>.<method> in its NS table to handler "ns.method", events via event.add(name, ...). ContentInjector injects V77 content scripts + shim; attachExt(ctx, web, offscreen=false) gives extension-origin pages window.chrome; offscreen=true keeps only chrome.runtime (like a real offscreen document).
- EngineHost: hidden WebView at https://appassets.androidplatform.net/ext/_engine.html running shared.js + sites.js + background.js (V77 service worker). proxyFor(req, tabId) = native network (CORS headers, cookies, HeaderModes rules per hop), GET/HEAD only. ext(uri) serves assets/ext. eval(js) runs a script in the engine. addLog / status / showStatus. init order in start(): ContentInjector, TabsApi, DownloadsApi, HeaderModes, Sniffer, OffscreenHost.
- TabsApi: tabs.*, runtime.sendMessage / tabs.sendMessage routing, alarms, windows, no-op stubs, onInstalled/onStartup. tabs.create / runtime.openOptionsPage to popup/queue/manga/history/options.html open ExtScreen windows; openTab(url).
- TabManager: one WebView per tab; ext pages opened as tabs (Tab.isExt). host() returns the Activity. shouldInterceptRequest -> ext assets, or proxyFor (ext tab), or Sniffer.onRequest (web tab).
- DownloadsApi.kt + DownloadService.kt (S7, NOT re-attached since): native chrome.downloads (OkHttp, MediaStore, foreground service, blob: read from the owning page). headerProvider hook set by Sniffer.
- HeaderModes (S8): declarativeNetRequest modifyHeaders. Sniffer (S8): webRequest events to the engine only, probes media urls.
- OffscreenHost (S9): chrome.offscreen create/close/hasDocument + runtime.getContexts (OFFSCREEN_DOCUMENT, BACKGROUND, POPUP, TAB). One hidden WebView on ext origin (offhost.html -> iframes offscreen.html). V77 does HLS/DASH merge there (remux.js, lib/mux.min.js), network via proxyFor.
- ExtScreen (S10): V77 popup/queue/manga/history/options pages as full-screen Dialog windows (open(activity,url), closeAll, isScreen, urlOf). Non-window links -> new tab. MainActivity menu rows: Media Grabber, Queue, Downloads, History, Settings, Check for updates, version, Engine status.
- EngineApi (S11/S12): ask(msg, cb)/send(msg) = runtime message to the engine with sender url popup.html (V77 then trusts msg.tabId, same as its popup); jobs() = storage.session mgJobs; history() = storage.local mgHist; fmtSize/fmtDur.
- FloatingDl (S11): draggable button over the page (count of hls/dash/video/audio from get-state of the active tab, poll 3s) + quality sheet (sheet_media.xml). Row -> start-job {tabId,key,variant|fmt}; V77 sets auto=1 so the S9 hidden document runs it.
- DownloadsScreen (S12): full-screen Dialog (screen_downloads.xml): V77 jobs with Pause/Resume/Cancel/Remove/Clear + Saved files Open/Show (chrome.downloads.open/show through EngineHost.eval).
- Other files that exist (never touched here, not attached): MainActivity.kt, UpdateManager.kt, Util.kt, res (colors mg_bg, mg_text, mg_text_dim, mg_outline, mg_primary, mg_surface_variant; layouts activity_main.xml, sheet_tabs.xml; drawable bg_url_bar).
- V77 messages used from native: get-state, start-job, job-pause (on), job-cancel, job-remove, jobs-clear, plus the CONTENT_MSG list in TabsApi for page frames.
- CHANGELOG.txt is the only changelog again (0.0.20 merged the S13-S19 entries; CHANGELOG_NEW.txt is deleted by DELETE.txt in the 0.0.20 zip).

- ExtUpdater (S16, ExtUpdater.kt): hot update of the ext bundle (assets/ext) without an APK. CI (build.yml, pasted by hand) computes MGB_NATIVE_HASH = fingerprint of everything except assets/ext (and the appVersionName line) -> BuildConfig.NATIVE_HASH, and attaches MGB-ext-b<run>-n<hash>.zip (ext files + _bundle.json {build,native}) to every release. UpdateManager.check: ext zip with SAME hash and build > max(VERSION_CODE, hot build) = ext-only dialog (reuses dialog_update layout); different hash and newer APK = normal APK dialog. Zip is checked (zip-slip, size, _bundle.json, manifest, background/shared/sites + content scripts), unpacked to filesDir/ext_hot/b<run>, prefs mgb_ext.dir; used from the NEXT start only (dialog asks to close MGB). ContentInjector.read and EngineHost.page ask ExtUpdater first (readText / open), then the built-in assets. Hot dir is dropped at start if build <= VERSION_CODE or hash differs. Manual check with nothing newer + hot active offers Reset to built-in. No hash/sha256 check of the zip itself (HTTPS + GitHub only).
