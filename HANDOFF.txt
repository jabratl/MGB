KNOWN RISKS (decide in the step, note in RESULT)
- 360dp width: bar content today = 4+44+34(shield)+url+34+40+4. Two arrows (2 x 36) leave the url field ~108dp. Rule: both arrows ON and screen width < 400dp -> arrows 32dp and the engine badge stays hidden; url field min 96dp.
- Per-site zoom vs default zoom: TextZoom.set removes the key at 100. With a default of 150 a site could never be pinned to 100. Step A2 changes the rule: remove the key only when value == default.
- Touchpad two-finger swipe reaches Android views as MotionEvent.ACTION_SCROLL with AXIS_HSCROLL only on some devices / Android versions. Best effort: if the owner's device sends nothing, keep the switch but say so in the hint (decision rule in A3).
- Force zoom changes page layout on web apps that block zoom on purpose: default OFF, plus a per-site opt-out (A3).
