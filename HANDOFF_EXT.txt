== after S0, version 0.0.93 ==
API (object ExtRegistry, package com.jabra.mgb):
- init(ctx)  call once before use (idempotent). Cleans .stage_*/.old_* folders.
- all() / enabled() / get(id) -> Info(id,name,version,manifestVersion,description,permissions,hostPermissions,
  contentScriptCount,popup,options,background,enabled,dir)
- prepare(ctx, uri, cb: (Result<Staged>) -> Unit)   uri from file picker; cb on main thread; Staged.info / Staged.existing (update?)
- commit(staged, cb: (Result<Info>) -> Unit) / discard(staged)   always call one of them after a successful prepare
- setEnabled(id, on), remove(id), file(id, rel) (safe path), isValidId(id)
Storage: filesDir/exts/<id>/ ; enabled flag = prefs "mgb_exts" key "off" (set of disabled ids). Not inside ext folder.
