MGB 0.0.12 (S10b)
- Menu (⋮) now has Media Grabber, Queue, History and Settings. They open the extension windows from 0.0.11.

MGB 0.0.11 (S10)
- Extension screens: the Media Grabber popup, Queue, Manga reader, History and Settings pages open as full-screen windows (title, back, reload, close) instead of browser tabs. Opened by V77 itself (open options, open manga, links between its pages).
- A link to a website or to the downloader/player page opened from a window becomes a normal tab and the window closes.
- The popup stays narrow and centered on wide screens. window.close() in a page closes the window.
- runtime.getContexts lists an open window as POPUP.

MGB 0.0.10 (S9)
- Hidden background downloads: chrome.offscreen (createDocument, closeDocument, hasDocument) now works. V77 joins HLS/DASH segments in a hidden page (offhost.html -> offscreen.html with remux.js and mux.min.js) instead of opening a downloader tab. Network goes through the engine proxy (CORS-free, header rules).
- chrome.runtime.getContexts returns the hidden document, the engine (BACKGROUND) and extension tabs, with contextTypes / documentUrls / tabIds filters.
- Menu > Engine status shows the hidden document state.

MGB 0.0.9 (S8)
- Stream detection: pages are watched while they load. HLS/DASH playlists, subtitles, video/audio files and stream-looking requests are reported to the engine (V77 webRequest), including the Referer the page used, so V77 can list them and download with the right headers.
- Header rules: declarativeNetRequest (V77 Referer/Origin/site-header rules) now works for the engine and for extension pages (downloader, player, manga).
- Extension pages opened as tabs now load remote files through the engine proxy, so cross-site requests are no longer blocked.
- Direct downloads send the Referer the page used for that host.
- Menu > Engine status shows header rule counts and sniffer counters.

MGB 0.0.8 (S7)
- Downloads: chrome.downloads now works (download, search, pause, resume, cancel, open, show, removeFile, erase + onCreated/onChanged/onErased). http(s), data: and blob: urls.
- Files are saved to the phone Downloads folder (same sub-folder names V77 asks for). Resume after pause or network loss. Progress notification while downloading, tap a finished one to open the file.
- Asks for notification permission once, on the first download.

MGB 0.0.7 (S6 fix)
- Build fix: a comment in EngineHost.kt contained a nested comment opener, which broke compilation. No feature change.

MGB 0.0.6 (S6)
- Engine: V77 background.js now runs in a hidden WebView (EngineHost). Its network requests are done natively, so CORS never blocks them.
- Messages: runtime.sendMessage / tabs.sendMessage route between the engine, extension pages and page frames (TabsApi).
- tabs.* (get, query, create, update, remove, reload, getCurrent) + onCreated/onUpdated/onActivated/onRemoved; windows.*, alarms.*; runtime.onInstalled/onStartup; cosmetic APIs (badge, context menu...) are accepted and ignored.
- Extension pages can open as tabs (https://appassets.androidplatform.net/ext/...), web pages cannot navigate there.
- Menu (⋮) > Engine status: shows whether background.js started + last log lines, with a Copy button.

MGB 0.0.5 (S15)
- In-app update: menu (⋮) > Check for updates, plus a silent check on start (every 12h). Reads the latest GitHub Release, downloads the APK with progress, opens the system installer.
- Needs a public repo; first install of this version must be done by hand once.

MGB 0.0.4 (S4+S5)
- S4: chrome.* shim (assets/shim/chrome-shim.js) + ChromeBridge.kt: storage local/sync/session + onChanged, runtime (getURL, getManifest, sendMessage, onMessage), generic forwarding of tabs/downloads/DNR/... to Kotlin handlers.
- S5: V77 (v2.79.2) copied as is into assets/ext; ContentInjector.kt injects hook.js + content.js (all frames, from manifest) into every tab.
